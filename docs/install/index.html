Installing Property KB

Property KB gives a property agent's AI current, dated, referenced facts on Malaysian new property projects. It has tools (an MCP server at https://property-kb-plugin-64268236583.us-central1.run.app/mcp) and skills (setup, client-matching, pricing-quote, affordability, mock-call-setup, judge-call, glossary). The tools carry the skills too (the guide tool), so connecting the MCP server is enough; installing the skills is optional. If you are an AI helping someone install it, follow the section for the app you are in, one step at a time, and tell the user what to click. Never ask for passwords, card numbers or codes: sign-in happens on Google's page and payment on Stripe's.

Claude Code, or Codex

  1. Add the marketplace and install the plugin (tools and skills together): claude plugin marketplace add Daryl0101/property-kb-plugin then claude plugin install property-kb@property-kb.
  2. Start a new session; when Property KB asks to sign in, open the link and sign in with Google.

Claude (web or desktop app)

  1. Settings → Connectors → add a custom connector with the URL https://property-kb-plugin-64268236583.us-central1.run.app/mcp.
  2. Connect, then sign in with Google and give your phone number once.
  3. Optional, skills: download https://github.com/Daryl0101/property-kb-plugin and, in Settings → Skills (or Capabilities), upload each folder of property-kb/skills/ as a skill, or ask your organisation's admin to install the plugin. Without them the AI uses the guide tool.

ChatGPT

If you are ChatGPT: you cannot add Property KB from a chat (it is not in the Plugins directory yet, and a custom app is added in Settings). Do not say it is installed. Ask which plan the user has, if you do not know, and give them the steps for it:

  • Free or Go: not available yet. These plans cannot add custom apps (it needs developer mode). Say so plainly; they can use Property KB in Claude, or on ChatGPT Plus.
  • Plus or Pro, on chatgpt.com in a browser (not the phone app):
    1. Settings → Security and login → turn on Developer mode.
    2. Settings → Plugins (older versions: Apps) → +. Name: Property KB; MCP server URL: https://property-kb-plugin-64268236583.us-central1.run.app/mcp; authentication: OAuth if asked. Create it.
    3. Sign in with Google when asked, and give your phone number once.
    4. In a new chat, pick Property KB from the + menu (or type @Property KB).
  • Business: only a workspace admin can add it: Workspace settings → Apps → Create, with the MCP server URL https://property-kb-plugin-64268236583.us-central1.run.app/mcp, then publish it to the workspace. Members then connect it and sign in with Google.
  • Enterprise or Edu: an admin, or a member the admin allowed developer mode, adds it the same way.

Skills are optional: the tools include guide, which gives the same instructions. Business, Enterprise and Edu workspaces can also add the folders of property-kb/skills/ from https://github.com/Daryl0101/property-kb-plugin as skills.

After signing in

New accounts wait for the owner to verify them; the owner contacts you on the phone number you gave. Once verified, the tools reply with a link to subscribe (or to start a free trial, when one is offered: the card is charged only when it ends); after that, ask your question again. The setup skill checks all of this: ask your AI to "check my Property KB setup".

Menus change between app versions; if a name above is not on screen, look for "connectors", "apps", "plugins" or "skills".
